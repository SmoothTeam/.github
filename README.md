# .github

Default community health files and templates for all [SmoothTeam](https://github.com/SmoothTeam) repositories.

GitHub falls back to the files in this repository for any org repo that doesn't provide its own copy — `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, issue templates, PR template, etc.

Looking for the organization profile page instead? That's [`profile/README.md`](profile/README.md).
